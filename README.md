# あんスタ好き顔9選

GitHub Pages用の静的サイトです。

## 構成
- `index.html`
- `style.css`
- `script.js`
- `images/` 50枚のSVG

## 公開
GitHubリポジトリのルートに上記ファイルを置き、
Settings → Pages → Deploy from a branch → `main` / `/ (root)`
で公開してください。

## 画像
アップロードされた50枚の画像を、キャラクター名に対応するファイル名へ整理し、
PNGをSVGへ埋め込んでいます。

画像の利用・公開については、権利者・公式の利用条件を確認してください。
